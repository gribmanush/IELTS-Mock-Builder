Build your own IELTS Academic mock test

Type in your own passages and questions, upload the listening audio, and set the correct answers. Then take the test on the same screen layout as IELTS on computer, with automatic marking for Listening and Reading.

How it works

  1. Name your mock.
  2. Listening: upload the recording, then add questions to Parts 1–4. Each part must have exactly 10 questions, as in the real test.
  3. Reading: type or scan a photo of each of the 3 passages, then add their questions. The total must be exactly 40.
  4. Writing: type the Task 1 and Task 2 questions. You can add a chart image for Task 1.
  5. Answers: set the correct answer for every question. You can accept several answers and choose whether capital letters matter.
  6. Take the test. When a section is finished, its box turns green with a ▶ Start button. Press it to begin that test.

The question types, numbering and timing are fixed to the IELTS format, so every mock looks and works like the real exam. Your mocks are saved in this browser automatically. Use Export to keep a backup file or share a mock, and Import to load one.
